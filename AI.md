# AI Usage

## Tools Used

- ChatGPT

## What I Used AI For

I used ChatGPT as a learning, brainstorming and review tool throughout the project.

I used it for:

- Brainstorming and refining parts of the story and puzzle design.
- Checking the logic of the Twilight Toy Derby.
- Generating initial visual concepts that I could attempt to convert into ASCII art.
- Planning the coding flow before implementation.
- Learning Git and GitHub, which I had not used before this project.
- Explaining unfamiliar C syntax and concepts when I became stuck.
- Reviewing code I had written for bugs or logic problems.
- Discussing different ways of implementing game-state logic.
- Reviewing the finished puzzle chains for inconsistencies.
- Helping organise and review the project documentation.

I wrote and tested the C implementation myself. When I encountered concepts I had not yet learned during my MSc, I used ChatGPT alongside other research to understand them before applying them to the project.

## Incorrect or Unhelpful Suggestions

Not every AI suggestion was useful or correct.

Some examples included:

- ChatGPT generated overly complicated artwork that did not survive conversion to 80×25 ASCII.
- Some early versions of the toy riddle were overdone, contained too much rhyming or used rhyming schemes that did not make sense.
- Various puzzle ideas did not meet the design standards I wanted for the game.
- ChatGPT sometimes lost track of earlier design decisions. During the design phase, for example, we had discussed a possible female nemesis, but later it introduced the player's dad instead. I had to remind it of the earlier design direction.
- Some suggestions made technical sense but did not make sense from a player's perspective. I had to consider how a human would actually interact with the game rather than accepting the suggestion simply because it worked logically.

## How I Verified AI Suggestions

I did not automatically use suggestions generated by ChatGPT.

I reviewed suggestions against my own design requirements and tested code changes by compiling and running the program.

For puzzle design, I worked through the logic myself to make sure the clues produced the intended solutions. I also used an external playtester who had not been given the solutions. This revealed an inconsistency in the final number and symbol clues that had not been caught simply by compiling and running the program.

When ChatGPT suggested syntax or programming concepts that I had not used before, I used research and testing to understand how they worked before incorporating them into the project.

The final design decisions and decisions about which suggestions to accept, change or reject were my own.
