# Research

## Git and GitHub

### Why I needed to learn this

I had not previously used Git or GitHub and needed to understand and learn how to version-control the project and publish the repository. 

### Resources

- YouTube
- ChatGPT
- Git/GitHub documentation

### What I learned

I learned the difference between Git and Github. Git is stored on my computer which tracks version changes and GitHub is the online repository that I push my git to in order to share my project with others.

I learned that the terminal command git --version in terminal gives you the version installed on your system.

I learned that the terminal command git init initializes an empty Git repository in my project folder.

I learned that the terminal command git status tells me the current state of my project compared with what I've recorded.

I learned that the terminal command git add stages files or changes for the next snapshot, and git add . stages the changes in the current project.

I learned that the terminal command git commit creates a new snapshot/version of my project from the changes I staged. Or git commit -m to add a message to the commit.

I learned that the terminal command git rm --cached <file>... will unstage a file.



### How I applied it

After doing a little research I was able to initilize Git for my project.
